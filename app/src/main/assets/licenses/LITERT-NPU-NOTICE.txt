Distribution review (2026-10-18): the first-party Apache license does not
establish all transitive binary licenses. Original AAR LICENSE and
THIRD_PARTY_NOTICE files are retained with their full contents and hashes in
runtime-license-sources.json. The LM and Tensor notices include a Google
Runtime Environment GPL entry whose relationship to the shipped Android
binaries is unresolved. This is not a finding that GPL code is linked.
Full NPU builds remain release candidates pending component/source mapping.
Portable builds contain neither LiteRT-LM Java API nor its native plugins.
See docs/NPU-DISTRIBUTION.md for the review scope and upstream evidence.
